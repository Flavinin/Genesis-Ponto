# SPRINT 01 — Planejamento e Levantamento de Requisitos

**Data de início:** 17/10/2026  
**Projeto:** Gênesis Ponto  

## 1. Descrição da Sprint

No dia 17 de outubro de 2026, iniciamos o desenvolvimento do projeto **Gênesis Ponto**, com o objetivo de identificar e propor uma solução para os problemas enfrentados pela empresa Gênesis Suprimentos, principalmente em relação às dificuldades de alguns funcionários no registro de ponto e no controle das horas extras trabalhadas.

Durante essa primeira etapa, entramos em contato com os *stakeholders* (partes interessadas no projeto) para compreender melhor as necessidades da empresa e identificar as principais funcionalidades que deveriam ser implementadas no sistema.

Com base nas informações obtidas, iniciamos o levantamento dos requisitos funcionais, a organização do repositório no GitHub e a elaboração da documentação inicial do projeto.

## 3. Desenvolvimento das Atividades

### Levantamento de Requisitos Funcionais

A partir do contato com os stakeholders, identificamos as principais necessidades da empresa e definimos as funcionalidades iniciais do sistema. Entre elas, destacam-se o cadastro de funcionários, o registro de entrada e saída, o controle dos intervalos e o cálculo das horas trabalhadas.

### Organização do Repositório no GitHub

Realizamos a estruturação inicial do repositório no GitHub, organizando os espaços destinados ao código-fonte, aos requisitos funcionais e não funcionais, às Sprints e à documentação do projeto.

Essa organização tem como objetivo facilitar o acompanhamento das atividades, o versionamento dos arquivos e o desenvolvimento colaborativo entre os integrantes da equipe.

### Documentação Inicial do Sistema

Iniciamos a elaboração da documentação do Gênesis Ponto, registrando o problema identificado, os objetivos do projeto e a solução proposta para atender às necessidades da Gênesis Suprimentos.

## 5. Considerações Finais

A Sprint 01 foi fundamental para estabelecer as bases do desenvolvimento do **Gênesis Ponto**, permitindo compreender as necessidades da empresa e organizar as primeiras atividades do projeto.

Com a conclusão dessa etapa, conseguimos definir os requisitos iniciais, estruturar o repositório e iniciar a documentação necessária para orientar as próximas Sprints.

Dessa forma, o projeto avançou da identificação do problema para o planejamento de uma solução, preparando a equipe para iniciar o desenvolvimento das funcionalidades do sistema.
