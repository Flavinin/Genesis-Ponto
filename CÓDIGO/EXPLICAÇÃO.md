# 💻 GENESIS PONTO
### Documentação do Código-Fonte

**Projeto Integrado Multidisciplinar (PIM) — UNIP**

O Genesis Ponto é um sistema de controle de ponto eletrônico desenvolvido em linguagem C para a empresa Gênesis Suprimentos.

## 🧩 Funcionamento

### Cadastro de funcionários
Permite cadastrar os funcionários utilizando matrícula e nome.

### Registro de ponto
Registra os horários de entrada, saída para intervalo, retorno do intervalo e saída final.

### Histórico
Permite consultar os registros realizados por cada funcionário.

### Horas trabalhadas
Calcula as horas trabalhadas, descontando os intervalos.

### Resumo de frequência
Apresenta os dias trabalhados, atrasos e horas extras.
