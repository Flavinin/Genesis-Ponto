# 🕒 GÊNESIS PONTO

## 📖 Sobre o Projeto

O **Gênesis Ponto** é um sistema de controle de jornada de trabalho desenvolvido em linguagem C, como parte do Projeto Integrado Multidisciplinar (PIM) da Universidade Paulista (UNIP).

O projeto tem como finalidade propor uma solução tecnológica para a empresa **Gênesis Suprimentos**, visando melhorar o gerenciamento dos registros de entrada, saída e intervalos de seus colaboradores.

Por meio de uma interface de terminal, o sistema permite cadastrar funcionários, registrar horários e consultar o histórico de ponto, centralizando informações e contribuindo para uma gestão mais organizada.

## 🏢 Sobre a Empresa

A **Gênesis Suprimentos** é a organização utilizada como objeto de estudo para o desenvolvimento deste projeto.

A partir da análise de seus processos internos, foram identificadas oportunidades de melhoria relacionadas ao controle e acompanhamento da jornada dos colaboradores.

O sistema proposto busca atender a essas necessidades utilizando conceitos de programação, engenharia de software e gestão de projetos.

## ⚠️ Problema Identificado

O controle inadequado dos registros de jornada pode gerar dificuldades administrativas, como:

- Falta de centralização das informações.
- Dificuldade para consultar horários registrados.
- Inconsistências nos registros de entrada e saída.
- Dificuldade para acompanhar horas trabalhadas e intervalos.
- Possíveis erros no acompanhamento de atrasos e horas extras.

Diante desse cenário, surgiu a proposta de desenvolver o **Gênesis Ponto**, buscando tornar esse processo mais organizado, acessível e confiável.

## 🎯 Objetivos

### Objetivo Geral

Desenvolver um sistema em linguagem C capaz de auxiliar no gerenciamento da jornada de trabalho dos funcionários da Gênesis Suprimentos.

### Objetivos Específicos

- Permitir o cadastro e a identificação dos colaboradores.
- Registrar horários de entrada, intervalo e saída.
- Armazenar informações para consultas posteriores.
- Disponibilizar o histórico individual dos funcionários.
- Implementar o cálculo das horas trabalhadas.
- Possibilitar a identificação de atrasos e horas extras.
- Aplicar conceitos de engenharia de software e desenvolvimento estruturado.

## 📋 Metodologia de Desenvolvimento

O desenvolvimento do Gênesis Ponto utiliza a metodologia ágil **Scrum**, permitindo organizar as atividades em etapas denominadas Sprints.

Durante o projeto, foram realizadas atividades de levantamento de requisitos, planejamento, modelagem e desenvolvimento do protótipo.

A equipe também utiliza registros de reuniões e documentos técnicos para acompanhar a evolução das entregas.

### Etapas de Desenvolvimento

| Etapa | Atividades |

| Modelagem | Elaboração de diagramas UML |

## 🖥️ Funcionamento do Sistema

O protótipo utiliza uma interface de terminal, permitindo que o usuário interaja com o sistema por meio de um menu de opções.

Entre as principais operações estão:

1. Cadastrar funcionários.
2. Consultar funcionários cadastrados.
3. Registrar horários de entrada e saída.
4. Registrar intervalos.
5. Consultar o histórico de ponto.

As informações são armazenadas em arquivos de texto, permitindo a recuperação dos dados em execuções posteriores do programa.

## 📊 Resultados Esperados

Espera-se que o Gênesis Ponto contribua para:

- Melhor organização dos registros de jornada.
- Maior facilidade de acesso às informações.
- Redução de inconsistências nos registros.
- Automatização dos cálculos de jornada.
- Apoio ao acompanhamento administrativo dos colaboradores.
